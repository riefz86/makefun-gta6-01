Solmar Heat — an original open-world crime game in the sun-soaked coastal city of Solmar: steal cars, run story missions, outrun the police, and make the city yours. Runs entirely offline in a desktop browser, built with three.js.

## Run it

```sh
npx serve game
```

Then open http://localhost:3000 in a desktop browser. Or serve `game/` with any static file server and open `index.html`.
